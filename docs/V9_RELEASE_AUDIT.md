# V9 Service Railway — release candidate audit

Plan: `V9_PLAN.md`. V8.1 main baseline acdc0b2dc588fc37ace0c0ff328235f98dd03e1c. Original visual identity and saves retained. V9 is an authored, Tiny Tower-inspired simulation, not a clone or a calibrated human-retention model.

## Changes
28 permanent catalog blueprints (16 new room compositions), six categories, 25 simultaneous carriage slots, unique new builds/refits, grandfathered existing duplicates. One construction bay: initial 90 s, geometric growth capped at 6 h; no income/boarding until completed. First upgrade immediate; later restoration durations grow from 3 min to 1 h per level. Batch upgrades pay the sum and take the sum of individual durations. Three paid service lots per commercial room, 1/2 boarded workers unlock the second/third; staff have housing capacity and dream job stock bonuses. Whole-train and per-room supply controls avoid tap-heavy busywork. Empty commercial stock retains 10% of normal service factor; housing earns modest passive rent. Overall rate scale .14, level income multiplier 1.18 rather than 1.27, fares reduced. Existing high balances/levels are deliberately not confiscated. New saves see full pacing; voluntary timetable reset is available under existing rules. Existing duplicate rooms can be refitted to new blueprints.

## Architecture-specific security review
No new network API, authentication, payment, server, dependency, or data egress. Auth/session/OAuth/GraphQL/SQL/SSRF/server request-smuggling threats are not applicable to this static offline build; reassess if backend is introduced. New save fields bounded; validation rejects prototype-key or unsafe type lookups by existing own-property gates; duplicated orders and simultaneous construction rejected, exact payment atomic; clock credit capped to 8 h, segmented event loop bounded, no user-supplied markup or asset URL. Existing strict CSP, escaped train name, backup migration, cache origin scope and unrelated cache preservation retained. Art assets contain passive local data only; no external fonts or requests. Local clock/save tampering cannot be prevented as server-authoritative anti-cheat without a backend. Original security suite rerun; not a complete independent penetration test.
