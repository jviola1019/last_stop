## New V8 behavior
- 20 room levels, 5 visual grades and four sequential optional workshop commissions (level 5, 9, 13, 17), each adding 12% of uncommissioned room earnings; up to +48%. Cost is 55% of the standard next-level price at the stage threshold. No separate currency. 25 carriages × 4 commissions = 100 possible commissions per train. Workshop purchases are blocked during a pending refit; refitting keeps commissions and charges positive investment differences. New timetable resets room investments but preserves lifetime rank claims.
- Restore to next visual grade: atomic quote equals the exact sum of single-level prices. Confirmation before charging; no partial upgrade or maximum-level overflow. Show the immediate per-room forecast on the basic upgrade button (current occupancy, neighbors and other conditions; not guaranteed future earnings).
- Ten lifetime stop ranks (1 to 10,000); 42 total stamps possible from one-time claims, no time-limited pressure. Rank claims validate against lifetime stop gate, survive voluntary prestige, and are separate per fleet save. Navigation cue for unclaimed rewards.
- Real renderer generates four distinct workshop thumbnails, not unrelated reference art. Tier-specific fascia, metal, enamel, badges, lighting, furnishings and masterwork crest; bounded raster cache keys include commission state. Seven revised non-original locomotive sprites retain viewBox and model silhouettes, native 318×226 pixel grid, shell shading, reflections, detailed running gear and aligned model-specific moving wheels. Original painted steam locomotive and sunset retained. A visual review identified black glazing due to a clipping injection matching a definition rather than the displayed path; generator corrected and decoded pixels checked. This is reproducible authored digital pixel art, not a fully commissioned matching painterly art set.
- Sticky catalogue navigation, responsive rank grid, accessible named reward cue, actual-image previews. Updated standalone and service worker cache revision. Additive v6 save schema retained for safe import of existing V3–V7 saves; rollback to an older client can discard V8-only fields, so export before rollback.

## Tests and scope
- `npm run verify`: 73 passing unit tests, TypeScript check, static and self-contained HTML builds. New tests cover all 12 carriage types and all four commission stages, actual earnings ratio, exact cost, gate, charge and refit retention, old-save migration, unsafe/forged fields, one-time rank rewards, prestige behavior, currency reachability and atomic next-grade quote.
- `node scripts/policy-stress.mjs`: 24 annual seeded policy simulations, 8,760 day-end states, no rejected purchases; short visits 95–96 workshop commissions / 6 ranks; regular 99–100 / 7; collector 99–100 / 8; optimizer 100 / 9. Carriage diversity after a year 8–9; peak levels 18/19/19/20. All profiles capped at 25 cars, which is intentional. Synthetic policies now include workshop purchases and rank rewards. Not player retention or real-world backtesting.
- `node scripts/balance.mjs --long`: deterministic baseline without new optional workshop/rank purchases: active 25 cars / max level 19; casual 25 cars / max level 17 at year end.
- Browser grand suite: desktop and phone viewport, buy workshop, verify paid coin change and rendered distinct previews, restore to max visual grade, claim rank, verify repeat claim disabled; prior engine/heritage/story/manifest/season/malicious-name checks retained. Real-origin suite extends V7 to test persistence of workshop and rank state under Chromium/Firefox/WebKit. See CI and JSON results for actual outcomes.
- Security review: preserve production CSP, use escaped user text and data-only renderer-generated preview PNGs, no network dependencies; validate save fields and use exact transaction guards. Offline owners can edit saves. Not independent accessibility/security certification.

## Independent acceptance limits
Real iPhone/Android and Windows installation, signed Windows installer, sustained hardware frame pacing/battery, actual OS PWA install prompts, human usability/retention, commissioned painterly fidelity and independent WCAG/security review are not certified by these automated tests. Production deployment requires successful final commit CI and merge. Earlier V7 success is not evidence that V8 has already passed remote CI.
